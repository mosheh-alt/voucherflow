# VoucherFlow uploader (Chrome add-on)

Uploads a VoucherFlow submission to the AAC charity portal. You log in to the portal yourself
(no passwords are stored). It opens "Add New Vouchers", adds the pictures, waits until each one
says "Uploaded", clicks Continue, and stops before Submit. After you submit, it tells VoucherFlow,
which marks the submission as sent.

Install: unzip → Chrome → chrome://extensions → turn on "Developer mode" → "Load unpacked" → pick this folder.
